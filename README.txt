# English Kids Interactive - Versión completa ampliada

## Qué trae esta versión

- Niveles A1, A2, B1 y B2 activos.
- Más temas por nivel.
- Más lecciones por tema.
- Se mantienen emojis.
- Se mantiene voz automática del navegador.
- Se agregaron más tipos de ejercicios.

## Cómo actualizar

Reemplaza estos archivos en tu proyecto:

- index.html
- style.css
- script.js
- data/lessons.js

Luego abre el navegador y presiona Ctrl + F5.
